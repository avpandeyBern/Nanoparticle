This folder contains the significantly expanded manuscript, publication-grade figures, and an EndNote-ready reference library.

## How to restore the EndNote citations and bibliography

1. Open EndNote and create a **new, empty library** (File → New).
2. Import the library: **File → Import → File**, choose `Nanoparticle_review_references.ris`, Import Option **Reference Manager (RIS)**. The 41 records import and receive record numbers **1–41 in file order**, matching the `#N` in the manuscript codes.
3. Open `Nanoparticle_review_expanded.docx` in Word with the EndNote (CWYW) tab active.
4. Click **Update Citations and Bibliography**. EndNote scans the `{Author, Year #N}` codes, formats the in-text citations, and builds the reference list in your chosen output style.

> Tip: import into an *empty* library so record numbers line up exactly. If you merge into an existing library, match by author + year if a record number differs.
